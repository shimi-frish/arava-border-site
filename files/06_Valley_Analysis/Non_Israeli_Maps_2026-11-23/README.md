# עמק הערבה במקורות לא-ישראליים (23.11.2026)

בקשת המנחה: לאסוף מפות ירדניות, ערביות ובינלאומיות שמראות את תיחום עמק הערבה, ולהשוות אותן לעמק הסופי (Arava_Valley_Final_2026-11).

- הדוח: עמק_הערבה_במקורות_לא_ישראליים_עם_מפות_2026-11-23 (PDF ו-DOCX). הגרסה הראשונה, בלי המפות, נשמרה גם היא.
- georef/: מפות מעוגנות ב-UTM 36N (EPSG:32636), בפורמט JPEG-TIFF עם מסכה:
  - TransJordan_250k_Kerak_1941: מחלקת הקרקעות והמדידות של עבר הירדן, 1941. NLA nla.obj-233522746. אינה מוגנת עוד בזכויות יוצרים. עוגנה לפי 144 צמתים של רשת פלשתינה, RMS 23 מ'.
  - AMS_K502_Aqaba/Maan/Jerusalem_1961: שירות המיפוי של צבא ארה"ב, נחלת הכלל (PCL UT Austin). עוגנו לפי 154–180 צמתים של רשת UTM ED50, RMS 17–35 מ'.
  - קובצי ה-json הם נקודות הבקרה (GCP, Ground Control Points).
- JVA_law_zone_vs_valley.gpkg: "העמק" לפי חוק פיתוח עמק הירדן 1988, אזור 2 (קו גובה 500 מ', Copernicus).
- Atlas_of_Jordan_2013_depression_unit.gpkg: דיגיטציה של היחידה מאיור I.2 (Al-Bilbisi). IoU 0.70 מול העמק הסופי.
- Copernicus_DEM_GLO30_Arava_60m_UTM36.tif: מודל הגבהים של סוכנות החלל האירופית (ESA).
- src/: הסריקות המקוריות. איורי האטלס מוגנים בזכויות יוצרים, לשימוש מחקרי בלבד, ואין לפרסם אותם באתר.
- scripts/: הסקריפטים של הניתוח והאיורים.

שמעון פריש, מחקר לתואר דוקטור, הטכניון. מנחים: פרופ' מקסים שושני ופרופ' אביעד שפירא. כל הזכויות שמורות.
