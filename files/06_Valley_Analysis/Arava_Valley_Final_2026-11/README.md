## שדות בחתכים (וב-CSV)

`valley_sections_stats_2026-11-17.csv` מכיל את אותם נתונים בטבלה. מרחקים בק"מ מהקו הישר, ערך חיובי = מערבית לקו.

* s_km: מרחק לאורך הקו הישר מחוף המפרץ.
* width_km: רוחב העמק בחתך.
* west_edge_off_km / east_edge_off_km: מיקום השוליים.
* centre_off_km: מרכז העמק.
* thalweg_off_km, thalweg_z_m: התלווג וגובהו.
* mandate1942_off_km: קו הגבול במפת המנדט 1942 (ריק אם הקו לא חוצה את החתך).
* thalweg_minus_centre_km, mandate_minus_thalweg_km, mandate_minus_centre_km: הפרשים.
