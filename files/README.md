# גבול ישראל–ירדן / הערבה – מבנה התיקייה

**לפתיחה: `Israel_Jordan_Arava_MASTER.qgz`** – הפרויקט הכללי, עם כל השכבות ונתיבים יחסיים.

| תיקייה | תוכן |
|---|---|
| `00_Projects` | פרויקטים ישנים (organized, פרויקט גבול ישראל ירדן, SHIMI, yafit). הנתיבים בהם עודכנו. |
| `01_Borders` | קווי גבול: 1942–58, 1994, גבול יפית, Gvul_Nayad (zip ופתוח) |
| `02_Topography_SRTM` | DEM (Mosaic Rasters), שיפועים (Mosaic_slope), חיתוכים, אריחי hgt |
| `03_Hydrology` | אגני ניקוז מ־SRTM + outlet, נחלים OSM, שכבות סחף נחלים |
| `04_Geology` | שכבות וקטור של המכון הגיאולוגי + מפות גאולוגיות סרוקות |
| `05_Historical_Maps` | Historical_Maps, Historical_Maps1 (כפי שהיו) |
| `06_Valley_Analysis` | תיחום העמק 2026, קווי מרכז ופרופילים 2024, מפות ייחוס של שושני |
| `07_Base_LandUse` | OSM בסיס, landuse |
| `99_Archive` | כפילויות, בדיקות, גיבויי פרויקטים, חבילת ה־zip הישנה (10GB) |
| `_package_tools` | סנכרון ל־Google Drive (מעודכן לפרויקט הכללי) |
| `_reorg` | יומן ההעברה ו־`undo_moves.py` לביטול |

`Vector_Data` נשארה ריקה (אין הרשאת מחיקה) – אפשר למחוק אותה ידנית.
