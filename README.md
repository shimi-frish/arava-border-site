# אתר הצפייה – גבול ישראל–ירדן בערבה

**לפתיחה:** לחיצה כפולה על `index.html` (נפתח בדפדפן, לא צריך QGIS ולא צריך אינטרנט מלבד מפת הרקע).
לצפייה גם בקבצי CSV/MD/TXT מתוך האתר: `START_SITE.bat` (מפעיל שרת מקומי קטן עם Python של Anaconda).

## מה יש באתר
- **מפה** – כל השכבות של `Israel_Jordan_Arava_MASTER.qgz` באותן קבוצות, שמות וצבעים; לחיצה על ישות מציגה מאפיינים; קואורדינטות WGS84 ו-ITM.
- **דוחות ואיורים** – כל קובצי ה-PDF/Word והאיורים בתיקייה.
- **קבצים ותיקיות** – עץ התיקיות המלא (ללא `99_Archive`, `_reorg`, `_package_tools`), עם צפייה, הורדה והצגה במפה.

## מבנה
| תיקייה | תוכן |
|---|---|
| `data/vector` | השכבות הווקטוריות ב-GeoJSON (‎`.geojson` להורדה, ‎`.js` לטעינה באתר) |
| `data/raster` | הרסטרים כתמונות WebP מוקטנות ב-Web Mercator, בסגנון של QGIS |
| `data/config.js`, `data/files.js` | עץ השכבות והסגנונות, ורשימת הקבצים |
| `files` | העתקים של קובצי PDF, תמונות וטקסט לצפייה |
| `_build` | הסקריפטים שבנו את האתר (לא צריך לפרסם) |

## עדכון האתר אחרי שינויים בפרויקט
הסקריפטים ב-`_build` קוראים את ה-MASTER ואת הקבצים ומייצרים מחדש את `data` ו-`files`. כדאי לבקש מ-Claude להריץ אותם שוב.

## פרסום
התיקייה היא אתר סטטי. אפשר להעלות אותה (בלי `_build`) ל-GitHub Pages, Netlify או לשרת של הטכניון, או לשתף אותה כ-ZIP.

## האתר הציבורי ועדכונים
- כתובת: https://shimi-frish.github.io/arava-border-site/
- עדכון: שומרים את הפרויקט ב-QGIS ולוחצים פעמיים על `UPDATE_SITE.bat`. הוא בונה מחדש רק את השכבות והקבצים שהשתנו ומעלה ל-GitHub (בפעם הראשונה תתבקש התחברות ל-GitHub בדפדפן). צריך Git for Windows מותקן.
- קבצים שלא יפורסמו באתר הציבורי (למשל מאמרים של אחרים) רשומים ב-`_build/exclude_public.txt`.
